# 하키 데이터 매니저

아이스하키 선수의 나이별 득점률 데이터를 이용해 에이징 커브를 학습하고,
과거 선수 기록을 예측한 뒤 감독이 되어 현재 선수를 영입하는 데이터 분석 웹앱입니다.

## 사용 데이터
- 은퇴 선수 8명의 나이별 득점률
- 은퇴 선수 나이별 평균 득점률
- 현재 선수 10명의 나이별 득점률
- 5차 다항회귀식
  f(x)=2.35×10^-5 x^5 - 0.003181 x^4 + 0.171 x^3 - 4.563 x^2 + 60.44 x - 317.2

## 파일
- index.html : 화면 구조
- styles.css : 디자인
- data.js : 실제 선수 데이터
- script.js : 그래프, 예측 퀴즈, 감독 모드
- README.md : 프로젝트 설명

## GitHub Pages 업데이트
기존 저장소의 index.html, styles.css, data.js, script.js를 이 버전으로 교체한 뒤 Commit 하면 됩니다.
GitHub Pages가 main / (root)를 보고 있다면 변경사항이 자동으로 다시 배포됩니다.
